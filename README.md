# Project-S-Great-Restaurant (한입)

서울 맛집 지도 웹앱 — 카카오맵 기반 UI, 최근 리뷰 카드 바텀시트, 로그인/회원가입 모달.

## Getting Started

```bash
npm install
cp .env.example .env.local
# NEXT_PUBLIC_KAKAO_MAP_APP_KEY 입력
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- Kakao Maps JavaScript API
